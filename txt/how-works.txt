Pretty much the order stuff goes in

BIOS calls whatevers at 0x7C00
    Load kernel-setup into ram
    
    kernel-setup:
        disable interupts
        set up stack
        Do sum legacy shit for backwards compatability (A20 Line)
        Set up GDT (global descriptor table)
        Go into 32 bit OS (protected mode)
        jump to protected setup
    
    _protected_setup:
        set up stack
        fix the gaps in the gdt and tss
        jump to kmain

    Jump to kernel_trampoline

kernel_trampoline:
    indentity_map the kernel_trampoline

    map the kernel to the higher half

    jump to kmain

kmain:
    call interupt setup

    

interupt_setup:
    remap PIC
    init IDT
    remap all important IDT values
    remap the idtr, the interupt descriptor the cpu reads
    load the interupt descriptor by giving the cpu a pointer to it, not the actual struct
    re enable interupts



Paging ties into
    - Memory management
    - Schedulers / Process management
    - File systems / Loadin and storing stuff on disk
    
how paging works:
    each process has its own page directory that contains up to (4 GiB)
        inside each page directory is a contiguous array of page tables (4 MiB)
            inside each page table is a 1024 page table entries that map to the physical frames (4KiB)

    When editing a page,

    when a program writes to memory, the MMU checks the TLB (cache) for the frame, if it misses,
    it reads the 10 MSB to find the index of the PDE, then uses the CR3 register and the index to get the address of the PT,
    it then reads the next 10 SB to find the index of the PTE inside the PT,
    then it uses 20 of the bits in the PTE as the frame number in RAM, plus the offset of the 12 LSB in the virtual address


how an interupt gets to the cpu:
    pic/cpu get the vector
    check idt entry at that vector
    go to stub at that idt entry

    stub:
        CPU already pushed a whole bunch of stuff

        If trap gate:
            cli     (mabye not because trap gates are used for things like syscalls which may not want to disable interrupts)
        
        If cpu exception that doesn't push an error code:
            push dummy error code
        
        pusha:
            EAX
            ECX
            EDX
            EBX
            ESP
            EBP
            ESI
            EDI
        push ds
        push es
        push fs
        push gs
        push int_vector

        jump c handler

        pop everything

        If pic interupt
            send eoi at the end
